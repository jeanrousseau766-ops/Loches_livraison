WAWANPOST — VERSION B CORRIGÉE POUR VERCEL
==========================================
Le design de la version B est conservé. Nouveautés :
- nom du site : WawanPost ;
- navigation publique sans raccourcis vers tous les espaces ;
- administration privée (/admin redirige vers la connexion) ;
- espaces livreur/commerçant activés seulement après validation ;
- espace client après création du compte ;
- 100 % de la marge plateforme affectée à la micronation wawangame ;
- boutons Se connecter / Créer un compte réparés et visibles sur mobile ;
- messagerie administration : tout le monde, une catégorie ou un compte précis ;
- sondages par catégorie ou globaux, votes et résultats côté admin.

SI VOTRE DÉPÔT GITHUB EXISTE DÉJÀ
1. Ne créez pas un nouveau projet et ne supprimez pas votre base Neon.
2. Sur GitHub, ouvrez votre dépôt → Add file → Upload files.
3. Glissez tout le contenu du dossier extrait (src, drizzle, public,
   package.json, package-lock.json, etc.), pas un dossier parent autour.
4. Cliquez sur Commit changes.

DANS VERCEL — INDISPENSABLE POUR LA BASE
5. Projet → Settings → Environment Variables.
6. Ajoutez ou corrigez DATABASE_URL :
   - valeur = la chaîne complète « Pooled connection » copiée chez Neon ;
   - elle commence par postgresql:// ;
   - activez Production ET Preview ;
   - cliquez sur Save.
7. Vérifiez aussi ADMIN_PSEUDO, ADMIN_PASSWORD et DEMO_PASSWORD.
   Choisissez vos mots de passe ; ne les publiez pas.
8. Deployments → déploiement le plus récent → … → Redeploy.
   Si proposé, laissez « Use existing Build Cache » décoché.

VÉRIFICATION
9. Ouvrez https://VOTRE-URL/api/health : vous devez voir {"ok":true}.
10. Ouvrez https://VOTRE-URL/ pour retrouver le site.
11. /admin doit rediriger vers la connexion si vous n'êtes pas administrateur.

IMPORTANT
- Enregistrer une variable ne suffit pas : il faut REDÉPLOYER ensuite.
- Les avertissements jaunes « npm warn deprecated » ne bloquent pas le build.
- Vous n'avez ni .env, ni node_modules, ni .next à fabriquer.
- Ne partagez jamais la valeur complète de DATABASE_URL.
- Si une autre erreur apparaît, la partie utile est la fin de Build Logs,
  autour de la première ligne rouge « Error: », pas le début de l'installation.
- Cette archive ne contient aucun secret et aucune donnée de votre base Neon.
